📥 端對端收信與淨化管線

  • • 零 VPC / 零 NAT 成本：Lambda 無 VPC，Batch 執行於 Public Subnet 的 ARM64 Fargate Spot。
  • • 雙重防毒與垃圾信防護：單一容器整合 Rspamd（無狀態評分）與 ClamAV（S3 快取特徵庫，無庫時 Fail-Closed 保護）。
  • • 雙層 XSS 防護：Batch 預先淨化 `.html` 本文，`staffportal-frontend` 再以沙盒化 `<iframe>` 獨立隔離渲染。

🔐 跨雲無金鑰信任邊界（Zero Static Keys）

  • • AWS → GCP WIF：Batch 透過 `mailservice-batch-task-role` 換取 GCP 短期權杖，僅具 Ingest Bucket `objectCreator` 權限。
  • • GCP → AWS OIDC：`pythonportal` 以 Cloud Run SA ID Token 扮演 `mailservice-pythonportal-role`，僅可讀 `mail/` 與寫 `folder=sent/`。
  • • 雙雲 CI 隔離：AWS CodePipeline 與 GCP Cloud Build 各自獨立且不交叉持有對方雲端憑證。

🗂️ 統一 Hive 儲存模型與防誤刪護欄

  • • 跨雲一致分區：`mail/<type>/dt=YYYY-MM-DD/mailbox=<~路徑>/folder=<folder>/`，支援未來無痛導入 Athena / BigQuery。
  • • Scheme URI 路由：Firestore 紀錄完整 `s3://` 與 `gs://` URI，讀取端依前綴動態切換儲存客戶端。
  • • CI 破壞變更保護：GCP Cloud Build 透過 `check_plan.py` 阻擋非白名單資源的 delete/replace；Firestore Index 設為 `PREVENT`。
