架構總覽

點擊上方任一元件，檢視詳細技術規格與設計依據

本架構整合「us-west1 既有應用層與 Shared VPC」、「asia-east1 獨立 PDM/PLM 資料湖專案」及「地端 MSSQL ERP [XTABLENAME]」，透過 V4 Signed URL 達成台灣區零跨洲圖檔直連。

核心原則：資料與應用跨專案分離、無金鑰 IAM 授權
圖檔傳輸：台灣瀏覽器直連 asia-east1 GCS (零跨洲 Egress)
參考文件：ADR-0001 / ADR-0002 / ADR-0003

跨區混合雲與零跨洲流量 (ADR-0001)

  • • 流量分離：KB 級 API 走 us-west1 免費 e2-micro Nginx；MB 級圖檔由台灣瀏覽器透過 V4 Signed URL 直連 asia-east1 GCS。
  • • 動態浮水印：前端以 pdf-lib 即時壓印姓名、時間、版次與狀態並寫入 pdm_audit_events。
  • • 零新增固定月費：沿用 j-shared-vpc 與 WireGuard VPN 連接地端 ERP。

熱冷分層與 Git-like DAG (ADR-0002 / 0003)

  • • Firestore Enterprise：啟用 MongoDB 相容模式，單筆嚴格 < 4 KiB，支撐三層料號檢索與Trino 聯查。
  • • GCS 三區段湖倉：raw_vault/ 不可變原檔、curated_items/ 完整 14 項工程 JSON、ml_features/ 向量 Parquet。
  • • 單一物料 DAG：以 main、shop/jk、process/op10-t 分支追蹤血緣並自動偵測過期衍生圖。

ERP 防腐層與雙階段寫入 (MCP Spec)

  • • HTML Schema 防腐層：設計期編譯 9 份 .md 為 .html，執行期 Python HTML Parser 100% 決定論驗證與填預設值。
  • • Step a 料號提案：自動檢查 撞號，無圖號或撞號時推算 {客戶代號}-{MAX(N)+1} 並等待人工確認。
  • • Step b/c 交易寫入：單一 MSSQL Transaction 寫入 9 張表，成功後回寫 erp_item_code 雙向綁定。
