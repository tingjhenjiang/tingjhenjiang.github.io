Interactive Mode

雙層機械式防寫保護

  • • 資料庫層：專屬帳號 j_forensic 非 sysadmin，正式庫 [XTABLENAME] 強制 DENY INSERT/UPDATE/DELETE/ALTER。
  • • 應用層：guard.py 強制 READ UNCOMMITTED、單語句白名單與 MAX_DURATION=10m 自動停機。
  • • 沙盒隔離：寫入等價測試僅限 [XTABLENAME_SANDBOX] 並搭配 --rollback-only。

無損雙軌擷取與離線分析

  • • 無損封存：每次擷取完整保留 100% 原始事件於 raw_events.jsonl，不遺漏任何讀取或阻擋行為。
  • • 寫讀分流：預設檢視低雜訊 write_call_tree.jsonl，遇阻擋 (E18) 或公式時再展開去重後的 read_queries.jsonl。
  • • 零重測成本：erp-forensic analyze 於 <0.1 秒離線重切視角，不需重連資料庫。

ERP → MES → CNC 串接藍圖

  • • 兩層製令模型：加工製令 '9'（CNC＋委外混合製造）與廠內製令 '5'（純廠內組裝）。
  • • 品檢緩衝閘門：MES 持有 Pending QC Lot，彌補未購置原廠驗貨模組與存檔即過帳風險。
  • • 批次寫回：中站寫 BOMYZ 移轉單、末站寫 BMSLIP+SSLIP 組合單，不逐筆 M30 寫單。
