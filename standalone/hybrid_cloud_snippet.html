本架構以 GCP Shared VPC Host Project 為網路中樞，透過單一台雙堆疊 WireGuard Gateway VM（instance-wireguard-gateway-20260417）同時承擔 Site-to-Site VPN、Nginx L7 反向代理、Nginx L4 SMTP 透傳代理、Cloud Run 固定 IPv4/IPv6 出網 NAT 以及自動化 Certbot 憑證管理。
Dual-Stack IPv4/IPv6 Shared VPC WireGuard wg0 Nginx L7 + L4 Stream

1. Shared VPC 與雙堆疊路由

  • • 跨區雙 VPC：us-west1-prod（10.138.0.0/20）與 asia-east1-prod（10.140.0.0/20）均啟用 Standard Tier External IPv6。
  • • 三個 Service Projects：Staff Portal、Website 與 ERP Enhancement 透過 Direct VPC Egress 共享子網路與 DNS 轉發。
  • • 分流路由：Priority 800 導向地端 192.168.x.0/24；Priority 900 將標記 egress-via-wireguard-gateway 的全網流量導經 Gateway NAT。

2. WireGuard Gateway 與 Nginx 雙代理

  • • Nginx L7 反向代理（Play 4）：雙堆疊監聽 80/443，終止 TLS 1.2/1.3 並提供 300s 逾時保護，代理至 Cloud Run Staff Portal。
  • • Nginx L4 Stream 透傳（Play 5）：監聽內網 10.138.0.3:2525，強制 IPv4 出口透傳至 smtp-relay.gmail.com:587，保留端對端 STARTTLS。
  • • 隧道與出網解耦：vpc_egress_nat.service 獨立於 wg0 運行，確保隧道重啟不中斷 Cloud Run 固定 IPv4/IPv6 出網。

3. 安全邊界、憑證與 IaC 維運

  • • 動態 Cloudflare 白名單：Terraform 即時抓取 Cloudflare IPv4/IPv6 CIDR，並以 cloudflare-origin 標籤限縮暴露範圍。
  • • 最小權限密鑰管理：Secret Manager 依單一 Secret 授權；Certbot 透過 DNS-01 自動續簽萬用憑證並同步備份至 GCS。
  • • 自動復原與版本化：maintain_vpn_connection.service 監控 192.168.1.1 自動重連；所有組態由 Terraform 與 Ansible Play 1–6 冪等部署。
