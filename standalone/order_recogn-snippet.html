本系統支援兩種執行模式：透過 Vue 3 SPA 進行人工上傳、Prompt 測試與檢核寫單（Web Service），以及透過 Cloud Run Job 定時掃描 s@j.com 未讀 PDF 訂單並自動寫入XY ERP XTABLENAME（Batch Task）。

Python 3.12 + FastAPI Gemini Instant / Batch API Pure ADC (無 SA JSON 檔) MSSQL XTABLENAME.dbo

核心運算與雙模式管線

  • • Web Service：FastAPI + Uvicorn（Port 5050），啟動時預先快取 7 張 ERP 主檔與 Firestore Prompt 文件。
  • • Batch Task：設定 runningmode=task 執行 Gmail 掃描，支援 Gemini Batch Job 斷點續傳與防重複寫單。
  • • 智慧切換：≤20 筆採即時 generate_content；超過門檻自動切換 Gemini Batch API 降低成本。

安全憑證與零金鑰治理

  • • 純 ADC 認證：Dev 與 Prod 皆強制移除 GOOGLE_APPLICATION_CREDENTIALS，徹底淘汰 SA JSON 金鑰檔。
  • • 職責分離：Secret Manager 僅存 MSSQL 帳密；Gemini API Key 改由 GCP API Keys API 動態讀取並快取。
  • • Gmail DWD：透過 google.auth.iam.Signer 無金鑰簽章模擬 s@j.com。

XY ERP (XYerp) 資料表對應

  • • ORDER TABLE / ORDER DETAIL TABLE：寫入 OR_CLASS='3'（客戶訂貨單），依 OR_WKNO 檢查客訂單號防呆並採單一交易提交。
  • • 主檔驗證：寫入前驗證 （客戶）、（料號）、（幣別）、（單位）。
  • • 風險提醒：XY ERP 修改訂單採「先刪後增（DELETE + INSERT）」，後續若接 Trigger/OLAP 須綜合處理。
