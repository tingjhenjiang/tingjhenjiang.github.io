2026-07-22

Background

I’m not that frontended. I undertand HTML, CSS, Javascript, and rough VueJS, but frontends are not my top priority focus. For the past year, I have a mission from my job to craft a enterprise-facing portal website, which provide kinds of services my collegues need. Therefore, although I am not quite skilled to it, I need to make it work out. Thanks to agentic coding softwares, generative AI are there to help me, and with the help of the modern and popular testing-framework playwright-cli together, I can overcome many frontend problems.

Prerequistes

Configure a Browser to Support Remote Debugging

I created a application shortcut, which uses Edge as the target, whose target is:

"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222 --inprivate --remote-debugging-address=0.0.0.0 --user-data-dir="R:\Temp\EdgeDebugProfile"

Installing Playwright-cli and its Skills

Follow the guides on playwright-cli github repository.

Tell Agents to Use Corresponding Playwright-cli Commands

Add something in AGENTS.md to prompt the agent to use playwright-cli skills to do browser-automation tests, and the prerequisites to use playwright-cli is to

playwright-cli attach --cdp=http://localhost:9222
